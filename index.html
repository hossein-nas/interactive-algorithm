Five habits that matter more than any single algorithm

  1. Ask first, code later. Restate the problem; ask about size, order, duplicates, and empty input.
  2. Say the slow way out loud. A correct O(n²) answer with a clear path to better beats silence.
  3. Name the pattern and say why. "The array is sorted, so I can discard from either end": a reason, not a guess.
  4. Trace before you declare victory. One normal case, one edge case, one tricky branch.
  5. State complexity with the reason. "O(n), because each index is added and removed once."

Your redo log

The guide's rule: keep a log of problem · pattern · what I got wrong · date to redo, and redo each wrong problem after 3 days and again after 7 days. Patterns you keep getting wrong are your real study list.
