Topological sort

Put things in an order that respects every "before".

Book link: Grokking Algorithms chapter 6 ends by noting that some graphs describe an order ("brush your teeth before getting dressed" is not a rule, but "wake up" must come before "brush teeth"), and appendix material on topological sorting uses the same graph tools. This file turns that remark into a full tool. It continues v2's Course Schedule question (#6) and extends it with ordering, levels, and two famous harder problems.

Reach for it when

Prerequisites, build steps, "X must happen before Y", or detecting a cycle in a directed graph.

Two algorithms

Kahn: repeatedly take a node with in-degree 0. DFS: three colors; a back edge to a "visiting" node is a cycle.

O(V + E). An order exists only if the graph has no cycle.

1. The idea in plain English

Some tasks can only start after others have finished. You cannot put on shoes before socks, or compile a program before its libraries. If you draw an arrow A → B for "A must come before B", you get a directed graph of dependencies.

A topological order is a way to line up all the tasks in a row so that every arrow points forward: each task appears after everything it depends on.

One valid order: socks, pants, shirt, shoes, belt, jacket. Another: shirt, pants, belt, jacket, socks, shoes. There are usually many valid orders.

When does an order exist? Only if there is no cycle

If A must come before B, B before C, and C before A, no order is possible (a deadlock). A directed graph with no cycles is called a DAG (directed acyclic graph). A topological order exists exactly when the graph is a DAG.

So topological-sort problems come in two flavors that use the same algorithm:

  1. "Is there a valid order at all?" = "Is there a cycle?" (Course Schedule)
  2. "Give me a valid order." (Course Schedule II)

2. Two algorithms (both O(V + E))

Algorithm A: Kahn's algorithm (BFS with in-degrees)

In-degree of a node = how many arrows point into it = how many things it is still waiting for. A node with in-degree 0 has no unfinished prerequisites, so it can go now.

  1. Count the in-degree of every node.
  2. Put all in-degree-0 nodes into a queue.
  3. Repeatedly take a node from the queue, append it to the order, and for each node it points to, reduce that node's in-degree by 1 (one prerequisite finished). If that reaches 0, add it to the queue.
  4. If you processed all nodes, you have a valid order. If some nodes were never processed, they are stuck in a cycle.

Algorithm B: DFS with three colors (and reverse postorder)

Run DFS. Give every node a state:

  • 0 = unvisited,
  • 1 = visiting (on the current DFS path: still being explored),
  • 2 = done (completely explored).

If DFS reaches a node that is in state 1, it has found a back edge: a path that returns to an ancestor, which is a cycle. When a node's exploration finishes, append it to a list (postorder). The reverse of that list is a topological order.

An important detail for undirected graphs: the 3-color trick is for directed graphs. For an undirected graph, a cycle check is "DFS that reaches an already-visited node other than the one it just came from", or union-find (file 21).

3. How to recognize it

  • "Prerequisites", "dependencies", "must come before", "order of tasks/courses/builds".
  • "Can all tasks be completed?" (is there a cycle?)
  • "Return any valid ordering."
  • "Minimum number of rounds/semesters to finish everything" (levels of Kahn).
  • "Derive the ordering of letters/items from a sorted list of examples" (Alien Dictionary).
  • "Repeatedly remove the things that have no dependents" (peeling leaves).

Problem 1 · Course Schedule: can everything be finished? (LeetCode 207, Medium; v2 Q6)

Task. There are numCourses courses 0..n−1. prerequisites[i] = [a, b] means to take a you must first take b (edge b → a). Can you finish all courses? numCourses = 2, [[1,0]] → true. [[1,0],[0,1]] → false.

Idea. "Can finish all" ⟺ "no cycle" ⟺ Kahn processes all n nodes.

Trace. numCourses = 4, [[1,0],[2,0],[3,1],[3,2]] (edges 0→1, 0→2, 1→3, 2→3)

StepQueuePoppedIn-degrees after
start[0]0:0, 1:1, 2:1, 3:2
1[]01 → 0, 2 → 0: push both; [1, 2]
2[2]13 → 1
3[]23 → 0: push; [3]
4[]3all done: processed 4 of 4

With a cycle 0 → 1 → 0: both have in-degree 1, the queue starts empty, processed 0 of 2 → false.

function canFinish(numCourses: number, prerequisites: number[][]): boolean {
  const adj: number[][] = Array.from({ length: numCourses }, () => []);
  const indegree = new Array<number>(numCourses).fill(0);
  for (const [course, prereq] of prerequisites) {
    adj[prereq].push(course); // the edge goes prerequisite -> course
    indegree[course]++;
  }
  const queue: number[] = [];
  for (let i = 0; i < numCourses; i++) if (indegree[i] === 0) queue.push(i); // nothing to wait for
  let processed = 0;
  for (let head = 0; head < queue.length; head++) {
    const node = queue[head];
    processed++;
    for (const next of adj[node]) {
      if (--indegree[next] === 0) queue.push(next); // one fewer prerequisite outstanding
    }
  }
  return processed === numCourses; // fewer means a cycle blocked the rest
}

function canFinishDFS(numCourses: number, prerequisites: number[][]): boolean {
  const adj: number[][] = Array.from({ length: numCourses }, () => []);
  for (const [course, prereq] of prerequisites) adj[prereq].push(course);
  const state = new Array<number>(numCourses).fill(0); // 0 new, 1 visiting, 2 done
  function hasCycle(node: number): boolean {
    state[node] = 1;
    for (const next of adj[node]) {
      if (state[next] === 1) return true; // back to a node on the current path
      if (state[next] === 0 && hasCycle(next)) return true;
    }
    state[node] = 2;
    return false;
  }
  for (let i = 0; i < numCourses; i++) if (state[i] === 0 && hasCycle(i)) return false;
  return true;
}

console.log(canFinish(4, [[1, 0], [2, 0], [3, 1], [3, 2]])); // true
console.log(canFinish(3, [])); // true
func canFinish(numCourses int, prerequisites [][]int) bool {
	adj := make([][]int, numCourses)
	indegree := make([]int, numCourses)
	for _, p := range prerequisites {
		course, prereq := p[0], p[1]
		adj[prereq] = append(adj[prereq], course) // the edge goes prerequisite -> course
		indegree[course]++
	}
	queue := []int{}
	for i := 0; i < numCourses; i++ {
		if indegree[i] == 0 {
			queue = append(queue, i) // nothing to wait for
		}
	}
	processed := 0
	for head := 0; head < len(queue); head++ {
		node := queue[head]
		processed++
		for _, next := range adj[node] {
			indegree[next]--
			if indegree[next] == 0 {
				queue = append(queue, next) // one fewer prerequisite outstanding
			}
		}
	}
	return processed == numCourses // fewer means a cycle blocked the rest
}

func canFinishDFS(numCourses int, prerequisites [][]int) bool {
	adj := make([][]int, numCourses)
	for _, p := range prerequisites {
		adj[p[1]] = append(adj[p[1]], p[0])
	}
	state := make([]int, numCourses) // 0 new, 1 visiting, 2 done
	var hasCycle func(node int) bool
	hasCycle = func(node int) bool {
		state[node] = 1
		for _, next := range adj[node] {
			if state[next] == 1 {
				return true // back to a node on the current path
			}
			if state[next] == 0 && hasCycle(next) {
				return true
			}
		}
		state[node] = 2
		return false
	}
	for i := 0; i < numCourses; i++ {
		if state[i] == 0 && hasCycle(i) {
			return false
		}
	}
	return true
}

func exampleCanFinish() {
	fmt.Println(canFinish(2, [][]int{{1, 0}}), canFinishDFS(2, [][]int{{1, 0}}))                         // true true
	fmt.Println(canFinish(2, [][]int{{1, 0}, {0, 1}}), canFinishDFS(2, [][]int{{1, 0}, {0, 1}}))         // false false
	fmt.Println(canFinish(4, [][]int{{1, 0}, {2, 0}, {3, 1}, {3, 2}}))                                   // true
	fmt.Println(canFinish(3, nil))                                                                       // true
}

Complexity. Time O(V + E), space O(V + E).

Problem 2 · Course Schedule II: produce an order (LeetCode 210, Medium)

Task. Same input; return a valid order to take all courses, or an empty list if impossible. 4, [[1,0],[2,0],[3,1],[3,2]] → [0, 1, 2, 3] (also [0, 2, 1, 3] is valid).

Idea. Kahn's algorithm already produces the order: it is the sequence in which nodes leave the queue. Return it if its length is n, else [].

function findOrder(numCourses: number, prerequisites: number[][]): number[] {
  const adj: number[][] = Array.from({ length: numCourses }, () => []);
  const indegree = new Array<number>(numCourses).fill(0);
  for (const [course, prereq] of prerequisites) {
    adj[prereq].push(course);
    indegree[course]++;
  }
  const order: number[] = [];
  for (let i = 0; i < numCourses; i++) if (indegree[i] === 0) order.push(i); // the order doubles as the queue
  for (let head = 0; head < order.length; head++) {
    for (const next of adj[order[head]]) {
      if (--indegree[next] === 0) order.push(next);
    }
  }
  return order.length === numCourses ? order : []; // [] signals a cycle
}

console.log(findOrder(2, [[1, 0]])); // [ 0, 1 ]
console.log(findOrder(2, [[1, 0], [0, 1]])); // []
console.log(findOrder(1, [])); // [ 0 ]
func findOrder(numCourses int, prerequisites [][]int) []int {
	adj := make([][]int, numCourses)
	indegree := make([]int, numCourses)
	for _, p := range prerequisites {
		adj[p[1]] = append(adj[p[1]], p[0])
		indegree[p[0]]++
	}
	order := []int{}
	for i := 0; i < numCourses; i++ {
		if indegree[i] == 0 {
			order = append(order, i) // the order doubles as the queue
		}
	}
	for head := 0; head < len(order); head++ {
		for _, next := range adj[order[head]] {
			indegree[next]--
			if indegree[next] == 0 {
				order = append(order, next)
			}
		}
	}
	if len(order) == numCourses {
		return order
	}
	return []int{} // signals a cycle
}

func exampleFindOrder() {
	fmt.Println(findOrder(4, [][]int{{1, 0}, {2, 0}, {3, 1}, {3, 2}})) // [0 1 2 3]
	fmt.Println(findOrder(2, [][]int{{1, 0}}))                         // [0 1]
	fmt.Println(findOrder(2, [][]int{{1, 0}, {0, 1}}))                 // []
	fmt.Println(findOrder(1, nil))                                     // [0]
}

Complexity. Time O(V + E), space O(V + E).

Trick: using the answer array itself as the queue (with a head index) saves a separate structure.

Problem 3 · Parallel Courses: how many semesters? (LeetCode 1136, Medium)

Task. There are n courses (1-indexed). relations[i] = [prev, next]: take prev before next. In each semester you may take any number of courses whose prerequisites were all finished in earlier semesters. Return the minimum number of semesters, or −1 if there is a cycle. n = 3, [[1,3],[2,3]] → 2.

Idea. Kahn's algorithm, processed level by level: each "level" of the queue is one semester. All courses currently available (in-degree 0) go in the same semester; finishing them releases the next group. The answer is the number of levels (the length of the longest dependency chain).

function minimumSemesters(n: number, relations: number[][]): number {
  const adj: number[][] = Array.from({ length: n + 1 }, () => []); // 1-indexed
  const indegree = new Array<number>(n + 1).fill(0);
  for (const [prev, next] of relations) {
    adj[prev].push(next);
    indegree[next]++;
  }
  let current: number[] = [];
  for (let i = 1; i <= n; i++) if (indegree[i] === 0) current.push(i);
  let semesters = 0, taken = 0;
  while (current.length > 0) {
    semesters++; // everything in `current` is taken together this semester
    const following: number[] = [];
    for (const course of current) {
      taken++;
      for (const next of adj[course]) if (--indegree[next] === 0) following.push(next);
    }
    current = following;
  }
  return taken === n ? semesters : -1;
}
console.log(minimumSemesters(3, [[1, 3], [2, 3]])); // 2
console.log(minimumSemesters(3, [[1, 2], [2, 3], [3, 1]])); // -1
console.log(minimumSemesters(4, [[1, 2], [2, 3], [3, 4]])); // 4
func minimumSemesters(n int, relations [][]int) int {
	adj := make([][]int, n+1) // 1-indexed
	indegree := make([]int, n+1)
	for _, r := range relations {
		adj[r[0]] = append(adj[r[0]], r[1])
		indegree[r[1]]++
	}
	current := []int{}
	for i := 1; i <= n; i++ {
		if indegree[i] == 0 {
			current = append(current, i)
		}
	}
	semesters, taken := 0, 0
	for len(current) > 0 {
		semesters++ // everything in `current` is taken together this semester
		following := []int{}
		for _, course := range current {
			taken++
			for _, next := range adj[course] {
				indegree[next]--
				if indegree[next] == 0 {
					following = append(following, next)
				}
			}
		}
		current = following
	}
	if taken == n {
		return semesters
	}
	return -1
}

func exampleMinimumSemesters() {
	fmt.Println(minimumSemesters(3, [][]int{{1, 3}, {2, 3}}))         // 2
	fmt.Println(minimumSemesters(3, [][]int{{1, 2}, {2, 3}, {3, 1}})) // -1
	fmt.Println(minimumSemesters(4, [][]int{{1, 2}, {2, 3}, {3, 4}})) // 4
}

Complexity. Time O(V + E), space O(V + E).

Variants. Course Schedule III, Find All Recipes (LeetCode 2115), Sequence Reconstruction (LeetCode 444, is the topological order unique? Only if the queue never holds two nodes at once).

Problem 4 · Alien Dictionary (LeetCode 269, Hard)

Task. An alien language uses the Latin letters but in an unknown order. You get a list of words sorted by the alien dictionary order. Return a string of the letters in a valid alien order, or "" if the list is inconsistent. ["wrt","wrf","er","ett","rftt"] → "wertf".

The graph is hidden in the word list. Compare each pair of adjacent words. At the first position where they differ, the letter in the earlier word comes before the letter in the later word. That gives one edge. Later positions tell you nothing (the words were already ordered by that first difference).

Walk-through.

Adjacent wordsFirst differenceEdge
wrt, wrft vs ft → f
wrf, erw vs ew → e
er, ettr vs tr → t
ett, rftte vs re → r

A topological sort of the letters is w, e, r, t, f: "wertf" ✔.

Two traps to handle.

  1. Prefix trap: if a longer word comes before its own prefix (["abc", "ab"]), no order can make that valid → return "".
  2. Include letters that have no edges: every distinct letter must appear in the answer, even if it is unconstrained. So collect all letters first, with in-degree 0.

Also: if Kahn's algorithm processes fewer letters than exist, there is a cycle (a < b and b < a) → "".

function alienOrder(words: string[]): string {
  const adj = new Map<string, Set<string>>(); // letter -> letters that must come AFTER it
  const indegree = new Map<string, number>();
  for (const word of words) {
    for (const ch of word) {
      if (!adj.has(ch)) adj.set(ch, new Set());
      if (!indegree.has(ch)) indegree.set(ch, 0); // every letter counts, even without constraints
    }
  }
  for (let i = 0; i + 1 < words.length; i++) {
    const a = words[i], b = words[i + 1];
    if (a.length > b.length && a.startsWith(b)) return ""; // "abc" before "ab" is impossible
    for (let j = 0; j < Math.min(a.length, b.length); j++) {
      if (a[j] !== b[j]) {
        if (!adj.get(a[j])!.has(b[j])) {
          adj.get(a[j])!.add(b[j]); // a[j] comes before b[j]
          indegree.set(b[j], indegree.get(b[j])! + 1);
        }
        break; // only the FIRST difference tells us anything
      }
    }
  }
  const order: string[] = [];
  for (const [ch, d] of indegree) if (d === 0) order.push(ch);
  for (let head = 0; head < order.length; head++) {
    for (const next of adj.get(order[head])!) {
      indegree.set(next, indegree.get(next)! - 1);
      if (indegree.get(next) === 0) order.push(next);
    }
  }
  return order.length === indegree.size ? order.join("") : ""; // fewer letters means a cycle
}

console.log(alienOrder(["z", "x"])); // zx
console.log(JSON.stringify(alienOrder(["z", "x", "z"]))); // ""   (z < x and x < z: a cycle)
console.log(JSON.stringify(alienOrder(["abc", "ab"]))); // ""   (prefix trap)
func alienOrder(words []string) string {
	adj := make(map[byte][]byte) // letter -> letters that must come AFTER it
	indegree := make(map[byte]int)
	letters := []byte{} // letters in order of first appearance, for a stable answer
	for _, word := range words {
		for i := 0; i < len(word); i++ {
			if _, seen := indegree[word[i]]; !seen {
				indegree[word[i]] = 0 // every letter counts, even without constraints
				letters = append(letters, word[i])
			}
		}
	}
	edgeSeen := make(map[[2]byte]bool)
	for i := 0; i+1 < len(words); i++ {
		a, b := words[i], words[i+1]
		if len(a) > len(b) && strings.HasPrefix(a, b) {
			return "" // "abc" before "ab" is impossible
		}
		for j := 0; j < min(len(a), len(b)); j++ {
			if a[j] != b[j] {
				edge := [2]byte{a[j], b[j]}
				if !edgeSeen[edge] {
					edgeSeen[edge] = true
					adj[a[j]] = append(adj[a[j]], b[j]) // a[j] comes before b[j]
					indegree[b[j]]++
				}
				break // only the FIRST difference tells us anything
			}
		}
	}
	order := []byte{}
	for _, ch := range letters {
		if indegree[ch] == 0 {
			order = append(order, ch)
		}
	}
	for head := 0; head < len(order); head++ {
		for _, next := range adj[order[head]] {
			indegree[next]--
			if indegree[next] == 0 {
				order = append(order, next)
			}
		}
	}
	if len(order) == len(letters) {
		return string(order)
	}
	return "" // fewer letters means a cycle
}

func exampleAlienOrder() {
	fmt.Println(alienOrder([]string{"wrt", "wrf", "er", "ett", "rftt"})) // wertf
	fmt.Println(alienOrder([]string{"z", "x"}))                          // zx
	fmt.Printf("%q\n", alienOrder([]string{"z", "x", "z"}))              // ""
	fmt.Printf("%q\n", alienOrder([]string{"abc", "ab"}))                // ""
}

Complexity. Time O(C) where C is the total number of characters in all words (building edges) plus O(U + E) for the sort over U unique letters and E ≤ min(C, U²) edges. Space O(U + E).

Common slip: processing all pairs of words instead of only adjacent ones (adjacent suffices, because sortedness is transitive), or adding edges from every differing position.

Problem 5 · Minimum Height Trees: peeling leaves (LeetCode 310, Medium/Hard)

Task. A tree (connected, no cycles) has n nodes and n − 1 undirected edges. Choose any node as the root; the tree then has some height. Return the roots that give the minimum height (there are at most two). n = 4, edges [[1,0],[1,2],[1,3]] → [1].

Idea. The best roots are the center of the tree: the middle of its longest path. To find the center, peel the tree like an onion: repeatedly remove all current leaves (nodes with degree 1). What remains in the end (1 or 2 nodes) is the center.

This is Kahn's algorithm in a new disguise: instead of "remove nodes with in-degree 0", we "remove nodes with degree 1" layer by layer, until 1 or 2 nodes are left.

Why at most two centers. The longest path in a tree has some length. If it has an odd number of nodes there is one middle node; if even, two middle nodes. Peeling removes the same number of nodes from both ends of every long path each round, so it ends at the middle.

Trace. n = 6, edges [[3,0],[3,1],[3,2],[3,4],[5,4]]

RoundLeaves removedRemaining nodes
start0, 1, 2, 3, 4, 5
10, 1, 2, 5 (degree 1)3, 4
stop2 nodes leftanswer [3, 4]
function findMinHeightTrees(n: number, edges: number[][]): number[] {
  if (n === 1) return [0];
  const adj: number[][] = Array.from({ length: n }, () => []);
  const degree = new Array<number>(n).fill(0);
  for (const [a, b] of edges) {
    adj[a].push(b);
    adj[b].push(a);
    degree[a]++;
    degree[b]++;
  }
  let leaves: number[] = [];
  for (let i = 0; i < n; i++) if (degree[i] === 1) leaves.push(i);
  let remaining = n;
  while (remaining > 2) {
    remaining -= leaves.length; // peel off this whole layer
    const nextLeaves: number[] = [];
    for (const leaf of leaves) {
      for (const neighbor of adj[leaf]) {
        if (--degree[neighbor] === 1) nextLeaves.push(neighbor); // it just became a leaf
      }
    }
    leaves = nextLeaves;
  }
  return leaves.sort((x, y) => x - y); // the last layer is the center (1 or 2 nodes)
}

console.log(findMinHeightTrees(6, [[3, 0], [3, 1], [3, 2], [3, 4], [5, 4]])); // [ 3, 4 ]
console.log(findMinHeightTrees(1, [])); // [ 0 ]
console.log(findMinHeightTrees(2, [[0, 1]])); // [ 0, 1 ]
func findMinHeightTrees(n int, edges [][]int) []int {
	if n == 1 {
		return []int{0}
	}
	adj := make([][]int, n)
	degree := make([]int, n)
	for _, e := range edges {
		a, b := e[0], e[1]
		adj[a] = append(adj[a], b)
		adj[b] = append(adj[b], a)
		degree[a]++
		degree[b]++
	}
	leaves := []int{}
	for i := 0; i < n; i++ {
		if degree[i] == 1 {
			leaves = append(leaves, i)
		}
	}
	remaining := n
	for remaining > 2 {
		remaining -= len(leaves) // peel off this whole layer
		nextLeaves := []int{}
		for _, leaf := range leaves {
			for _, neighbor := range adj[leaf] {
				degree[neighbor]--
				if degree[neighbor] == 1 {
					nextLeaves = append(nextLeaves, neighbor) // it just became a leaf
				}
			}
		}
		leaves = nextLeaves
	}
	sort.Ints(leaves)
	return leaves // the last layer is the center (1 or 2 nodes)
}

func exampleFindMinHeightTrees() {
	fmt.Println(findMinHeightTrees(4, [][]int{{1, 0}, {1, 2}, {1, 3}}))                  // [1]
	fmt.Println(findMinHeightTrees(6, [][]int{{3, 0}, {3, 1}, {3, 2}, {3, 4}, {5, 4}})) // [3 4]
	fmt.Println(findMinHeightTrees(1, nil))                                              // [0]
	fmt.Println(findMinHeightTrees(2, [][]int{{0, 1}}))                                  // [0 1]
}

Complexity. Time O(n), space O(n).

The brute force it replaces: compute the height from every node as root (O(n²)) and take the minimum.

Common mistakes

  • Reversing the edge direction. In LeetCode 207, [a, b] means b before a: the edge is b → a. Draw one example first.
  • Forgetting nodes with no edges (isolated courses/letters must still be in the answer).
  • Declaring "no cycle" without counting processed nodes. Compare the number processed with V.
  • Using the 3-color DFS with just a boolean visited: a plain visited set cannot tell "on the current path" from "finished", so it reports false cycles in DAGs with shared descendants (a "diamond").
  • Using this on undirected graphs (cycle detection there is different).
  • Alien Dictionary: comparing non-adjacent words, ignoring the prefix case, or adding duplicate edges (inflating in-degrees).
  • Duplicate prerequisite pairs counted twice (inflating in-degrees): usually fine if you decrement per edge too, but deduplicate if you use a set-based graph.

1 · Find the cycle

Draw the graph for numCourses = 5 with prerequisites [[1,0],[2,1],[3,2],[4,3],[2,4]]. Is there a cycle? Which nodes does Kahn's algorithm not process?

Answer

Edges 0 → 1 → 2 → 3 → 4 → 2. Yes, a cycle: 2 → 3 → 4 → 2. Kahn takes 0, then 1; that drops 2's in-degree from 2 to 1, and it never reaches 0 because 4 is waiting on 3, which waits on 2. Processed: 0 and 1. Not processed: 2, 3, 4. It is the third preset of the course animations.

2 · Why a cycle blocks every order

Explain in two sentences why a topological order does not exist if there is a cycle.

Answer

Every node on a cycle has a predecessor on the same cycle that must come before it. Follow the cycle around and each node must come before itself, which is impossible.

3 · DFS order in your head

Write the DFS "postorder reversed" version of findOrder in your head: what is pushed when, and why reverse it?

Answer

Use the three colors. A node is pushed to post after all its outgoing neighbors finish, so everything that depends on it is already in the list. Reversing puts every node before everything it unlocks. A back edge to a "visiting" node means a cycle: return [].

// Course Schedule II with DFS: push each node AFTER everything it unlocks, then reverse.
function findOrderDFS(numCourses: number, prerequisites: number[][]): number[] {
  const adj: number[][] = Array.from({ length: numCourses }, () => []);
  for (const [course, prereq] of prerequisites) adj[prereq].push(course);
  const state = new Array<number>(numCourses).fill(0); // 0 new, 1 visiting, 2 done
  const post: number[] = [];
  function visit(node: number): boolean {
    state[node] = 1;
    for (const next of adj[node]) {
      if (state[next] === 1) return false; // cycle
      if (state[next] === 0 && !visit(next)) return false;
    }
    state[node] = 2;
    post.push(node); // everything after it is already in `post`
    return true;
  }
  for (let i = 0; i < numCourses; i++) if (state[i] === 0 && !visit(i)) return [];
  return post.reverse();
}

console.log(findOrderDFS(2, [[1, 0], [0, 1]])); // []
// Course Schedule II with DFS: push each node AFTER everything it unlocks, then reverse.
func findOrderDFS(numCourses int, prerequisites [][]int) []int {
	adj := make([][]int, numCourses)
	for _, p := range prerequisites {
		adj[p[1]] = append(adj[p[1]], p[0])
	}
	state := make([]int, numCourses) // 0 new, 1 visiting, 2 done
	post := []int{}
	var visit func(node int) bool
	visit = func(node int) bool {
		state[node] = 1
		for _, next := range adj[node] {
			if state[next] == 1 {
				return false // cycle
			}
			if state[next] == 0 && !visit(next) {
				return false
			}
		}
		state[node] = 2
		post = append(post, node) // everything after it is already in post
		return true
	}
	for i := 0; i < numCourses; i++ {
		if state[i] == 0 && !visit(i) {
			return []int{}
		}
	}
	for i, j := 0, len(post)-1; i < j; i, j = i+1, j-1 {
		post[i], post[j] = post[j], post[i]
	}
	return post
}

func exampleFindOrderDFS() {
	fmt.Println(findOrderDFS(4, [][]int{{1, 0}, {2, 0}, {3, 1}, {3, 2}})) // [0 2 1 3]
	fmt.Println(findOrderDFS(2, [][]int{{1, 0}, {0, 1}}))                 // []
}

4 · A unique order

How can you tell, from Kahn's queue, that the topological order is unique?

Answer

The order is unique exactly when the queue holds one node at every step. If two nodes are ready together, they could go in either order. Uniqueness also means the order is a single path through every node (each consecutive pair is joined by an edge).

5 · Critical path

Longest Path in a DAG / Critical path: given task durations, what is the minimum total time with unlimited parallel workers? (Hint: process in topological order and store the longest finish time per node.)

Answer

Process tasks in topological order and keep finish[v] = time[v] + max(finish[u]) over its prerequisites u (just time[v] if it has none). The answer is the largest finish time: the longest weighted path in the DAG. This is LeetCode 2050, Parallel Courses III.

// Critical path (Parallel Courses III): with unlimited workers, a task finishes at
// its own duration plus the latest finish among its prerequisites.
function minimumTime(n: number, relations: number[][], time: number[]): number {
  const adj: number[][] = Array.from({ length: n }, () => []);
  const indegree = new Array<number>(n).fill(0);
  for (const [prev, next] of relations) {
    adj[prev - 1].push(next - 1); // input is 1-indexed
    indegree[next - 1]++;
  }
  const finish = time.slice(); // a task with no prerequisites finishes at its own duration
  const queue: number[] = [];
  for (let i = 0; i < n; i++) if (indegree[i] === 0) queue.push(i);
  for (let head = 0; head < queue.length; head++) {
    const u = queue[head];
    for (const v of adj[u]) {
      finish[v] = Math.max(finish[v], finish[u] + time[v]); // wait for the slowest prerequisite
      if (--indegree[v] === 0) queue.push(v);
    }
  }
  return Math.max(...finish);
}

console.log(minimumTime(5, [[1, 5], [2, 5], [3, 5], [3, 4], [4, 5]], [1, 2, 3, 4, 5])); // 12
// Critical path (Parallel Courses III): with unlimited workers, a task finishes at
// its own duration plus the latest finish among its prerequisites.
func minimumTime(n int, relations [][]int, time []int) int {
	adj := make([][]int, n)
	indegree := make([]int, n)
	for _, r := range relations {
		adj[r[0]-1] = append(adj[r[0]-1], r[1]-1) // input is 1-indexed
		indegree[r[1]-1]++
	}
	finish := append([]int(nil), time...) // a task with no prerequisites finishes at its own duration
	queue := []int{}
	for i := 0; i < n; i++ {
		if indegree[i] == 0 {
			queue = append(queue, i)
		}
	}
	for head := 0; head < len(queue); head++ {
		u := queue[head]
		for _, v := range adj[u] {
			finish[v] = max(finish[v], finish[u]+time[v]) // wait for the slowest prerequisite
			indegree[v]--
			if indegree[v] == 0 {
				queue = append(queue, v)
			}
		}
	}
	best := 0
	for _, f := range finish {
		best = max(best, f)
	}
	return best
}

func exampleMinimumTime() {
	fmt.Println(minimumTime(3, [][]int{{1, 3}, {2, 3}}, []int{3, 2, 5}))                                 // 8
	fmt.Println(minimumTime(5, [][]int{{1, 5}, {2, 5}, {3, 5}, {3, 4}, {4, 5}}, []int{1, 2, 3, 4, 5})) // 12
}
